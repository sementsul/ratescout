## UC-50 — Встраиваемый виджет курсов (для бэклинков)
`write_widget()` → `dist/widget.js` (самодостаточный, без зависимостей) + `dist/widget-data.json` (8 пар,
курсы, обновляется в CI). Чужой сайт вставляет `<div class="ratescout-widget" data-pair="usdt-rub"></div>` +
`<script src="…/widget.js" async>`. Скрипт фетчит widget-data.json (GitHub Pages отдаёт с CORS `*`) и рисует
бокс с курсом + **бэклинком на ratescout.ru** (главный SEO-рычаг: обратные ссылки + реф-трафик + бренд).
Страница `/vidzhet/` (RU+EN, `render_widget_page`) — код для вставки, живое демо, список пар. В подвале/sitemap.
Радиус: +2 стр., 2 статических артефакта, подвал, sitemap. Статус: ✅ 8 пар, box() рендерит бэклинк (проверено).
JS виджета вынесен в исходник `widget.src.js` (build подставляет `{{BASE}}` → `dist/widget.js`). **Два режима:**
курс (`data-pair`) и мини-конвертер (`data-widget="converter"`: поле суммы + выбор пары + результат). Страница
`/vidzhet/` — галерея: оба виджета с живым демо и отдельными кодами вставки. Расчёт конвертера проверен
(2 BTC→11 025 140 ₽). Оба демо тянут `/widget.js` (тот же скрипт).
**Любая пара проекта:** режим `data-from`/`data-to` (произвольная пара) + конвертер по ВСЕМ 330 валютам —
