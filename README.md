# RateScout — мониторинг курсов обмена

Статический сайт-монитор курсов обмена криптовалют и денег на базе **BestChange**
(партнёрская программа). Хостинг — GitHub Pages, домен **ratescout.ru**.

## Что это
- Каталог **330 валют** (6 категорий) + страница на каждую валюту со всеми направлениями обмена.
- Конвертер направления по всему каталогу → deep-link в BestChange с реф-меткой.
- SEO: уникальные title/description/canonical, sitemap (335 URL), schema.org (FAQ/Breadcrumb), PWA.
- Комплаенс: страницы «что такое BestChange» / AML / раскрытие (FTC + ERID/ОРД + OFAC) / политика.

## Сборка
```bash
python3 build.py          # генерит dist/ (главная + 330 страниц валют + комплаенс)
```
Каталог валют — `currencies.json` (парсится из выгрузки BestChange через `parse_catalog.py`).

## Реальные курсы (Фаза 2)
`fetch_rates.py` тянет курсы по партнёрскому API и кладёт в `rates.json`, который `build.py` запекает
в страницы. Запускается в **GitHub Actions по расписанию** (`.github/workflows/deploy.yml`).

## 🔴 Безопасность ключа
Партнёрский ключ BestChange **никогда не попадает в браузер/репозиторий/сборку**:
- локально — в `.env` (в `.gitignore`);
- в CI — в **GitHub Secrets** (`BESTCHANGE_API_KEY`, `BESTCHANGE_RATES_URL`), используется только в раннере;
- workflow содержит guard: если ключ найден в `dist/` — деплой прерывается.

## Дисклеймер
RateScout — независимый информационный сервис, не обменный пункт. Ссылки ведут в BestChange; по партнёрской
программе возможно вознаграждение. Не является финансовой рекомендацией. 18+.
